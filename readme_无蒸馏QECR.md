# QECR-StereoDETR：无蒸馏实验工程

本目录是独立于旧 QDR 蒸馏版本的新工程。正式实验不读取教师缓存，也不计算教师蒸馏损失。

## 当前研究结论

1. 已形成第一创新点：查询级三维定位质量感知置信度校准，并在V09中与强续训起点组合；
2. V01—V05、V07—V08、V10—V14、V20均已按预注册门槛完成筛选或否决，负结果保留但不包装成有效创新；
3. G7 Oracle诊断通过，但V22训练期轴向IoU损失的正式配对Car Moderate变化`-0.0144 AP`，已经否决；当前不运行新的完整训练，先做下一轮可学习性归因。

## 正式入口

训练与评估只使用：

```bash
python tools/训练与评估_无蒸馏QECR.py --config <版本配置>
```

不要使用旧 QDR 工程中的教师缓存脚本。当前目录内从 QDR 复制来的旧兼容代码默认全部关闭。V01、V02 已完成但没有超过 V00；新增的 V03、V04 用基线安全融合修复查询深度直接覆盖原始深度的问题。
