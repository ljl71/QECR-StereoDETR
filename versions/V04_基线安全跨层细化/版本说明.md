# V04 基线安全跨层细化

## 消融目的

在 V03 已防止查询深度完全覆盖原始基线的前提下，单独验证“跨解码层概率分布细化”的边际贡献。

## 唯一结构变量

相对 V03，只将：

```yaml
model:
  query_depth:
    cross_layer_refine: true
```

其他设置保持不变：基线安全融合开启，`alpha`初始0.05、上限0.50，单点采样，不启用极线校正和几何门控。

## 配置与输出

```text
配置：versions/V04_基线安全跨层细化/config.yaml
输出：outputs/QECR消融实验/V04_基线安全跨层细化/
```

## 运行条件

只有 V03 达到《V03版本说明》中的通过条件，才运行 V04：

```bash
bash scripts/训练一个QECR版本.sh \
  versions/V04_基线安全跨层细化/config.yaml
```

V04 的直接对照是 V03，不是 V00；`V04 - V03` 才是跨层细化的边际增益。同时仍需报告 V04 相对 V00 的总增益，判断完整方案是否恢复并超过基线。

只有 V04 达到或超过 V00，才把后续 V15—V18 迁移到这条安全融合分支上。
