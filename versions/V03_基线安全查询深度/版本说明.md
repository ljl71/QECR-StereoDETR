# V03 基线安全查询深度

## 消融目的

验证 V01 的严格 IoU 精度下降是否主要来自“查询概率分布深度完全替换 StereoDETR 原始深度”。

## 唯一结构变量

相对 V01，仅新增基线安全融合：

```text
d_fused = d_base + alpha * (d_query - d_base)
alpha = 0.50 * sigmoid(a_layer)
```

- `d_base`：StereoDETR 原始深度图采样结果。
- `d_query`：V01 查询级局部概率分布的期望深度。
- 每个解码层只有1个可学习标量，3层共增加3个参数。
- `alpha` 初始为0.05，上限为0.50，防止未收敛查询深度破坏原始基线。
- 跨层细化关闭，不引入极线校正、多点采样或几何门控。

## 配置与输出

```text
配置：versions/V03_基线安全查询深度/config.yaml
输出：outputs/QECR消融实验/V03_基线安全查询深度/
```

## 运行与决策

```bash
bash scripts/训练一个QECR版本.sh \
  versions/V03_基线安全查询深度/config.yaml
```

V00 的 Car 3D AP_R40@0.70 Moderate 参考值为48.3226。为避免在单种子差异上过度决策，采用以下工程门槛：

- `>= 48.3226`：通过，继续 V04。
- `47.8 ~ 48.3226`：暂定为不确定区，先用新种子复跑 V03，并与同种子 V00 对照。
- `< 47.8` 或 Easy/Hard、Cyclist 同时广泛下降：暂停 V04，优先检查查询深度支路的损失和局部 bin 设计。

上述是资源调度门槛，不是统计显著性结论。
